
# Automatic Waste Segregation System

## About the Project
This project automatically segregates waste into different categories
using sensors and an Arduino Uno.

## Components
- Arduino Uno
- Moisture Sensor
- Inductive Proximity Sensor
- Servo Motor
- LDR
- L293D Motor Driver
- DC Gear Motor
- Conveyor Belt

## Working
The conveyor belt carries the waste through the sensing section.
The inductive proximity sensor detects metal waste and the moisture
sensor detects wet waste. Arduino processes the sensor signals and
controls the servo motor to direct the waste into the appropriate bin.

## Features
- Automatic waste segregation
- Metal detection
- Wet and dry waste detection
- Conveyor-based operation
- Reduced manual sorting

## Applications
- Smart waste-management systems
- Colleges and institutions
- Public places
- Smart-city projects
